# Словолесье

Личная мобильная картотека английских слов. Статический сайт, который можно открыть на GitHub Pages и добавить на главный экран телефона.

## Файлы

- `index.html` — интерфейс приложения.
- `app.js` — карточки, словарная справка, практика и локальное сохранение.
- `manifest.webmanifest`, `sw.js`, `icon.svg` — установка как веб-приложения и работа оболочки офлайн.

## Публикация через GitHub Pages

1. Загрузить эти файлы в корень GitHub-репозитория.
2. Открыть **Settings → Pages**.
3. В качестве источника выбрать ветку `main` и папку `/(root)`, затем сохранить.
4. Открыть опубликованную ссылку на телефоне. В меню браузера выбрать **Добавить на главный экран** или **Установить приложение**.

Слова и результаты занятий хранятся в локальном хранилище браузера на этом устройстве. Они не отправляются в GitHub. Кнопка `⋯` вверху позволяет скачать JSON-копию или импортировать её обратно. Автоматическая словарная справка запрашивается у Free Dictionary API; если сети нет или слово не найдено, карточку можно заполнить и поправить вручную.
